<h2 id="why">흩어진 기록을 하나의 흐름으로</h2>

캘린더에는 일정이 있고, 미리 알림에는 할 일이 있습니다. Apple Notes와 Obsidian에는 생각과 작업 기록이 남아 있고, 중요한 내용은 메일로 오기도 합니다.

Sisyphus Almanac은 이미 사용하던 원본을 중심으로 이 자료들을 연결하기 위해 시작했습니다. 일정을 선택하고 관련 메모와 할 일을 확인하며, 필요한 내용을 하루의 기록으로 이어갈 수 있습니다.

예정·캘린더·미리 알림·메모·Obsidian은 **이 Mac**을 기본 데이터 소스로 사용하며, 선택은 앱을 다시 실행해도 유지됩니다.

<h2 id="today">오늘 할 일을 한눈에</h2>

Today에서는 오늘 일정, 미리 알림, 다가오는 일정과 최근 메일을 한 화면에서 봅니다. 위의 Today 화면은 샘플 데이터로 구성했습니다.

<h2 id="daily-log">생각나는 대로, 빠르게 기록하기</h2>

불렛저널 방식으로 여러 줄을 적고, 저장 전에 미리보기를 확인합니다.

| 기호 | 동작 |
| --- | --- |
| `*` | 할 일 |
| `X` | 완료 |
| `>` | 이월 |
| `<` | 미래로 예약 |
| `@` | 일정 초안 |
| `-` | 메모 |
| `!` | 중요 표시 |
| `+` | 아이디어 |

~~~text
@ 10:00 작업 미팅
* 믹싱 수정하기
- 어제 작업과 비교하기
+ 새로운 플러그인 아이디어
! * 중요 파일 백업
~~~

`X`, `>`, `<`는 기호 뒤에 공백과 텍스트를 적고 미리보기에서 대상 할 일을 고릅니다. 이월과 예약에는 이동 날짜도 선택합니다. Daily Log의 일정 초안과 할 일은 Almanac에 저장됩니다. Apple Calendar나 미리 알림에 저장하려면 빠른 입력에서 외부 저장 대상을 고릅니다.

**할 일·일정·메모·아이디어** 종류 메뉴(기본값: 할 일)를 고르거나 기호를 직접 입력합니다. 기호가 있는 줄은 기호가 우선합니다. **⌘⌥L**로 입력 이동, **⌘⇧P**로 미리보기, **⌘Return**으로 저장합니다. 한글 조합을 끝낸 뒤 저장하세요.

<h2 id="daily-review">하루를 정리하고 다음 날로</h2>

완료한 일과 남은 일을 검토하고 짧은 회고를 저장합니다. 이월하거나 예약하려면 할 일과 날짜를 직접 고릅니다. 이전 날짜에는 이동 이력이 남으며, 마지막 로컬 변경은 실행 취소할 수 있습니다.

상태 메뉴에서도 완료·이월·날짜 지정·중요 표시를 선택합니다. 적용 전에 대상 할 일과 날짜를 확인하세요.

<h2 id="paper-capture">종이 기록을 Daily Log로 · 시험 기능</h2>

Mac 내부 Apple Vision OCR을 사용합니다. 1.1.4에서는 선택 저장 충돌을 수정하고 원문 기호와 완료 후보를 직접 검토하는 조작을 더했습니다. 원본과 결과를 대조하며 본문·종류·날짜·기호·중요 표시를 수정한 뒤 선택한 항목만 저장합니다. 선택한 원문 기호와 명시한 일정 시각을 보존합니다. OCR의 별·당구장 기호와 일부 글자는 여전히 원본 확인이 필요합니다.

검토 창이 열린 동안 저장 실행 취소로 이미지와 검토 항목을 복원할 수 있습니다. 다른 이미지를 시작하거나 초안을 삭제하면 이전 실행 취소 기록을 비웁니다. 이미지는 20 MB·3,200만 화소로 제한하며 인식 중에는 닫기를 막고 손상 초안의 자동 덮어쓰기를 방지합니다. 다중 창·강제 종료·디스크 오류 복구는 미완료이므로 원본은 별도 보관하세요.

<h2 id="entries-by-date">날짜별 기록과 완료한 일을 찾아보기</h2>

빠른 기록 위의 날짜별 기록에서 전체·남은 할 일·완료 필터를 선택합니다. 날짜 입력, 앞뒤 날짜, 오늘, 기록 있는 날짜로 이동하며 Daily Review에는 별도 완료 목록이 있습니다. 완료 목록은 배정된 기록 날짜 기준이며 실제 완료 시각의 통계가 아닙니다. 이월하면 배정 날짜가 바뀌고 이동 이력은 유지됩니다.

<h2 id="calendar">일정에서 관련 자료까지</h2>

일·주·월 캘린더에서 Apple Calendar 일정을 살피고 일정 상세에서 Apple 미리 알림, 메모와 Mail 참조를 연결합니다. 믹싱 일정에 수정 요청 메일을 붙이거나 피아노 연습 일정에 관련 메모를 연결하고 원본을 열 수 있습니다.

캘린더 상단의 **일정 추가** 또는 **캘린더 앱 열기**를 사용합니다. 입력창은 보고 있는 날짜로 시작하며 저장에는 캘린더 전체 접근 권한이 필요합니다. 실서비스 일정 저장 검증은 미완료입니다.

<h2 id="notes">기존 기록은 그대로</h2>

Apple Notes 목록과 텍스트를 미리 보고 원본을 엽니다. Obsidian에서는 선택한 볼트의 Markdown을 찾아보고 원본 위치에서 엽니다.

<h2 id="mail">중요한 메일도 작업과 연결하기</h2>

Apple Mail에 설정된 활성 계정의 받은 편지함에서 계정당 최근 최대 12건을 읽고, 제목·발신자·날짜·읽음 상태를 표시합니다. Today에는 최근 3건이 표시됩니다. 일정 또는 미리 알림에 Mail 참조를 직접 붙여 Apple Mail에서 원본을 열 수 있습니다. Mail 조회에는 macOS의 접근 허용이 필요합니다. 보내기·답장·삭제는 Apple Mail에서 합니다.

**메일 앱 열기** 버튼으로 Apple Mail을 바로 열 수 있습니다.

대시보드 제목과 받은편지함 행에서 Apple Mail 원본을 엽니다. 방향키 선택 변경도 원본을 열 수 있습니다. 첫 로드와 수동 새로고침 방식이며 본문·첨부 미리보기는 제공하지 않습니다.

<h2 id="finance">Excel 가계부를 다시 만들지 않고</h2>

Finance에서 선택한 Excel 통합 문서를 읽기 전용으로 참조하고, 이름과 경로를 확인한 뒤 원본을 열 수 있습니다. OneDrive에 있는 통합 문서는 Finder의 로컬 동기화 폴더에서 고릅니다. Almanac은 파일 내용을 변경하지 않으며 서버 동기화는 OneDrive가 담당합니다.

한국어·영어는 시스템 또는 macOS 앱별 언어 설정을 따릅니다. 변경 후 재실행하세요. 개인 기록과 메일 내용은 번역하지 않습니다.

<h2 id="menu-bar">필요할 때 메뉴바에서</h2>

메뉴바의 단색 시지프스 아이콘에서 오늘 일정과 미리 알림 요약을 엽니다. 메뉴바 아이콘은 설정에서 켜거나 끌 수 있습니다. [Tuck](../../ko/software/tuck/)은 메뉴바 아이콘을 정리하는 별도 앱입니다.

<h2 id="name">왜 시지프스 알마넥인가?</h2>

Almanac은 날짜와 정보를 함께 담는 연감입니다. 시지프스는 매일 바위를 밀어 올리는 인물입니다.

하루의 할 일을 끝내면 다음 날 또 다른 일이 생깁니다. 하지만 매일은 완전히 같지 않습니다. 그 사이에 우리가 만든 것과 배운 것, 남긴 기록이 있습니다.

## 언어

시스템 또는 macOS 앱별 언어 설정을 따릅니다. 한국어·영어를 지원하며 다른 언어의 기본값은 영어입니다. 언어를 강제 고정하지 않습니다. 개인 기록·일정·메일 내용은 번역하지 않습니다.

## Paper Capture

- 선택 저장 뒤 목록을 비울 때 이전 배열 위치를 참조해 종료될 수 있던 문제를 UUID 기반 참조로 수정했습니다.
- 줄 앞 체크 표식과 줄 끝 X, 한글에 붙은 X를 완료 후보로 분리하고 직접 수정할 수 있게 했습니다.
- 원문 기호 선택과 완료한 할 일 항목을 추가했습니다. 별·당구장 기호의 정확한 자동 판별을 보장하지 않으며 중요 여부는 별도로 선택합니다.
- 원문 기호와 일정 시각을 기록에 보존합니다. 시각 지정 선택을 분리해 화면에만 기본 시각이 나타나는 불일치도 방지합니다. 기존 초안·Daily Log 형식은 유지합니다.
- 저장 실행 취소 시 원본 이미지와 수정 초안도 복원합니다. 새 이미지 가져오기·초안 삭제 후에는 이전 취소 기록을 지워 새 초안 덮어쓰기를 방지합니다.
- 날짜 제목은 항목과 분리하고 불확실하면 확인 경고를 표시합니다. 모든 항목은 기본 미선택입니다.
- 20MB·3200만 화소 제한과 인식 중 닫기 방지, 종료된 인식 작업 결과 무시 처리를 추가했습니다.
- 읽지 못한 초안의 자동 덮어쓰기를 방지하고 초안 보존 오류가 성공 문구로 가려지지 않게 했습니다.

## 날짜별 기록과 완료

날짜별 기록을 빠른 입력 위에 배치하고 전체·남은 할 일·완료 필터를 추가했습니다. 이전·다음 날짜, 날짜 선택, 오늘, 기록 있는 날짜 메뉴로 이동합니다. Daily Review에 완료한 할 일 목록을 명확히 표시합니다.

이 화면은 기록에 배정된 날짜 기준입니다. 별도의 실제 완료 시각별 통계가 아니며 이월 시 날짜와 이동 이력이 기존 방식대로 유지됩니다.

## 검증 범위와 제한

주신 손글씨 한 장으로 격리 앱에서 5개 항목·완료 3개, 저장·취소·재저장·중복 차단을 확인한 이전 수정에 더해 이번 공개 후보의 단위·한영 화면 시험을 수행합니다. 정확한 최종 결과는 검증 문서를 확인하세요. 빌드 성공을 전체 외부 서비스 회귀 통과로 간주하지 않습니다.

임시 서명·Apple 미공증 공개 테스트입니다. macOS가 실행을 차단할 수 있습니다. Apple silicon·Intel 바이너리를 포함하지만 Intel·최소 OS 실기는 미검증입니다.

별·당구장·일부 글자와 날짜는 여전히 오인식할 수 있으므로 원본 대조가 필요합니다. PDF·다중 페이지, OneDrive 기록 자동 백업·복구, Daily Log 연결 편집, Finance 메일 연결은 미구현입니다. Mail은 계정별 최대 12건·오늘 최근 3건·첫 로드와 수동 새로고침이며 주기 갱신은 없습니다. 본문·첨부 미리보기, 미읽음 유지 전체 조건, 원본 이동·삭제 복원과 느린 조회의 화면 응답도 미완료 또는 미검증입니다.

다중 창 잠금·강제 종료·디스크 오류 복구·드롭/클립보드 전체 조건·한글 IME 개별 키·실 Notes/EventKit/Finance/OneDrive 전체 회귀는 완료하지 않았습니다. 원본 사진을 별도 보관하세요. 기존 1.1.1~1.1.3 공개 파일은 변경하지 않습니다.

### 1.1.3 릴리즈 노트 · Build 114

2026년 11월 21일 · 공개 테스트

[공식 GitHub 릴리즈](https://github.com/JovarisAudio/SisyphusAlmanac-Releases/releases/tag/v1.1.3)

## 기록 입력과 검토

- Daily Log 입력에 할 일·일정·메모·아이디어 종류 메뉴를 추가했습니다. 기본값은 할 일입니다.
- 기호 직접 입력은 유지하며, 기호가 있는 줄은 기존 파서가 우선합니다. 저장 전 미리보기에서 종류를 확인하세요.
- 기록 상태 메뉴에서 완료·이월·날짜 지정·중요 표시를 사용할 수 있습니다. 중복 중요 메뉴를 정리했습니다.
- 입력 이동 ⌘⌥L, 미리보기 ⌘⇧P, 저장 ⌘Return을 지원합니다. 한글 조합 중 저장을 막는 검사를 추가했습니다.

## Paper Capture 시험 기능

- 이미지 파일 선택, 이미지 드롭, 클립보드 이미지 입력 경로와 Mac 내부 Vision OCR을 추가했습니다.
- 원본과 결과를 나란히 보고 내용·종류·날짜·중요 표시를 수정한 뒤 선택한 항목만 Daily Log에 저장합니다.
- 모든 OCR 항목은 기본 미선택입니다. 같은 날짜·종류·내용의 중복 후보가 있으면 저장을 멈춥니다.
- 외부 Calendar·Reminders에 자동으로 쓰지 않습니다.

## 캘린더와 Mail

- 캘린더 상단에 일정 추가와 캘린더 앱 열기를 추가했습니다. 일정 추가 창은 보고 있는 날짜로 시작합니다.
- 일정 저장에는 macOS 캘린더 전체 접근이 필요합니다. 저장 후 추가한 일정으로 돌아가는 경로를 연결했습니다.
- 대시보드 최근 메일과 받은편지함 행에서 Apple Mail 원본을 바로 엽니다. 방향키 선택 변경도 원본을 열 수 있습니다.
- Mail은 계정별 받은편지함 최대 12건과 대시보드 최근 3건을 제공합니다. 첫 로드·수동 새로고침 방식이며 주기 갱신 타이머는 없습니다.

## 한국어와 영어

시스템 또는 앱별 언어 설정에 맞춰 한국어·영어를 표시합니다. 날짜의 한국어 고정을 해제했습니다. 개인 기록과 메일 내용은 번역하지 않습니다.

## 확인한 범위

Universal Release 빌드, 단위 시험 7건, 한국어·영어 시작 UI, 종류·기호 파싱, 완료·이월·취소, 인쇄체 OCR 일부, 이미 읽은 메일의 실제 원본 대조를 확인했습니다. 캘린더 두 버튼과 일정 입력창도 설치 앱에서 확인했습니다. 모든 시험이 동일 시점의 최종 패키지에서 반복된 것은 아닙니다.

## 알려진 제한과 미검증

- 공개 테스트 버전이며 임시 서명 상태입니다. Apple 공증을 받지 않아 macOS가 실행을 차단할 수 있습니다.
- Paper Capture의 실제 한국어 손글씨 정확도, 드롭·클립보드 실기, 초안 재실행 복원과 저장 오류 복구는 충분히 검증하지 못했습니다.
- Paper Capture는 인식한 일정 시각을 저장하지 않습니다. 시각이 필요한 일정은 별도 일정 추가에서 입력하세요.
- 초안 손상·디스크 오류·여러 창에서 원본 보존이 완전히 보장되지 않습니다. 원본 이미지는 별도 보관하세요. 저장 성공 시 검토 이미지와 초안 항목은 비워집니다.
- PDF, OneDrive 기록 백업·복구, Daily Log 자료 연결 편집, Finance 참고 메일 연결은 미구현입니다.
- Mail 본문·첨부 미리보기·일반 메일함 선택은 제공하지 않습니다. 미읽음 단순 조회 전후 상태, 이동·삭제 후 원본 복원과 느린 조회 중 화면 응답은 미검증입니다.
- 실제 한글 조합 중 개별 키 조작, 외부 서비스 전체 회귀, Intel·macOS 15.0 실기, 모든 창 크기·모드 시험은 미완료입니다.
- 이번 캘린더 변경의 실제 일정 저장은 설치 앱 권한 미허용 상태로 검증하지 못했습니다. 시험 일정을 개인 원본에 임의 생성하지 않았습니다.

기존 1.1.1·1.1.2 공개 파일은 유지합니다. 기존 Daily Log 형식과 연결 메타데이터를 초기화하지 않습니다.

<h2 id="manual-section-1">설치와 언어</h2>

macOS 15.0 이상에서 DMG를 열어 Sisyphus Almanac.app을 Applications로 드래그합니다. 기존 앱은 종료한 뒤 교체하세요. Apple silicon·Intel 바이너리를 포함하지만 Intel 실기는 미검증입니다. 임시 서명·미공증 상태이며 macOS가 실행을 차단할 수 있습니다.

한국어·영어를 지원합니다. 시스템 또는 macOS 앱별 언어를 사용하며 변경 후 재실행하세요. 개인 데이터는 번역하지 않습니다.

<h2 id="manual-section-2">날짜별 기록과 완료 목록</h2>

Daily Log의 날짜별 기록은 빠른 기록보다 위에 있습니다. 전체·남은 할 일·완료 필터로 구분하세요. 이전·다음 기록 날짜, 날짜 선택, 오늘, 기록 있는 날짜 메뉴로 이동할 수 있습니다. Daily Review의 완료한 할 일 목록에서도 해당 날짜의 완료 기록을 확인합니다.

날짜는 항목에 배정된 기록 날짜입니다. 실제 완료 버튼을 누른 시각별 통계는 아닙니다. 과거 날짜에 배정된 일을 나중에 완료하면 원래 배정 날짜에 완료로 남습니다. 이월한 항목은 옮긴 날짜에 있고 이전 날짜에는 이동 이력이 남습니다. 제외한 기록은 기본 필터에서 숨깁니다.

<h2 id="manual-section-3">오늘과 자료 소스</h2>

‘이 Mac’은 실제 연결 자료이고 ‘샘플’은 예시입니다. 이전에 고른 데이터 소스는 재실행 후 유지됩니다. 샘플 일정과 실제 일정은 서로 다릅니다. 권한 요청은 해당 자료 화면에서 수행하며, 허용 여부는 시스템 설정의 개인정보 보호 및 보안에서 확인합니다.

<h2 id="manual-section-4">캘린더에서 일정 입력</h2>

1. 사이드바의 캘린더를 엽니다.
2. 날짜를 이동하고 일간·주간·월간을 고릅니다.
3. 상단 ‘일정 추가’를 누릅니다. 현재 보고 있는 날짜가 입력창의 기본 날짜입니다.
4. 제목·시작 날짜와 시각·길이·저장 캘린더를 확인합니다.
5. 접근 안내가 있으면 ‘접근 요청’을 누르고 macOS에서 허용합니다.
6. ‘일정 추가’로 저장합니다. 저장 성공 시 캘린더에서 해당 일정으로 돌아가도록 연결돼 있습니다.

직접 Apple 캘린더를 사용하려면 같은 위치의 ‘캘린더 앱 열기’를 누르세요. 이 버튼은 앱을 여는 기능이며 특정 일정으로 이동하거나 기존 일정을 편집하는 기능은 아닙니다. 실제 일정 저장 후 선택·갱신은 이번 설치본에서 아직 실기 검증하지 못했습니다.

<h2 id="manual-section-5">빠른 입력</h2>

빠른 입력에서는 일정 또는 미리 알림을 선택하고 저장 위치를 직접 고릅니다. 미리 알림은 필요하면 마감 날짜·시간을 지정합니다. 권한이 없거나 저장 위치·제목이 없으면 저장할 수 없습니다. 입력한 종류와 저장 서비스가 맞는지 확인하세요.

<h2 id="manual-section-6">Daily Log 기록</h2>

종류 메뉴의 할 일·일정·메모·아이디어를 고르면 기호 없이 여러 줄을 작성할 수 있습니다. 기본은 할 일입니다. 직접 기호를 입력한 줄은 기호가 우선합니다. 미리보기에서 저장 종류를 확인한 후 저장하세요.

```text
* 믹싱 확인
! * 오늘 마스터 검토
@ 14:00 피아노 연습
- 확인한 내용
+ 다음 곡 편성
```

Daily Log의 일정은 로컬 기록입니다. Apple 캘린더 일정 생성은 캘린더의 ‘일정 추가’ 또는 ‘빠른 입력’을 사용하세요.

입력 이동은 ⌘⌥L, 미리보기는 ⌘⇧P, 저장은 ⌘Return입니다. 조합 중 한글이 있으면 조합을 끝낸 뒤 실행하세요. 입력기별 상세 키 동작 전체는 미검증입니다.

<h2 id="manual-section-7">상태·이월·회고</h2>

기록의 상태 메뉴에서 가능한 항목에 대해 완료·이월·날짜 지정·중요 표시를 선택합니다. 이월·날짜 지정에서는 대상 날짜를 확인하고 적용합니다. Daily Review에서 남은 일을 정리하고 회고를 저장합니다. 마지막 로컬 변경은 실행 취소할 수 있지만 재실행 후까지 유지되는 무제한 취소 기능은 아닙니다.

X, >, < 기호를 직접 입력하는 기존 방식도 사용할 수 있습니다. 저장 전에 처리할 대상 할 일과 날짜를 확인하세요. 날짜 대화상자에서 Enter만으로 적용되지 않으면 적용 버튼을 누르세요.

<h2 id="manual-section-8">Paper Capture 시험 기능</h2>

1. Daily Log의 Paper Capture를 엽니다.
2. 이미지 선택으로 사진·캡처를 가져옵니다. 드롭·이미지 붙여넣기 경로도 있으나 실제 조작 검증은 미완료입니다.
3. 인식은 Mac 내부에서 실행됩니다. 원본 옆에서 본문·종류·날짜·중요 표시를 직접 확인하고 수정합니다.
4. 저장할 항목만 선택하세요. 초기에는 전부 미선택입니다. 낮은 신뢰도 표시는 재확인이 필요하다는 뜻입니다.
5. 선택한 항목을 Daily Log에 저장합니다. 같은 날짜·종류·내용의 중복 후보가 있으면 수정하거나 선택 해제해야 합니다.

한국어 손글씨 전체 정확도는 입증되지 않았습니다. 원문 기호와 완료한 할 일 항목에서 별·당구장·줄 끝 X 해석을 직접 고칠 수 있습니다. 20MB·3200만 화소 이하 이미지를 사용하세요. 인식 중에는 닫기가 제한됩니다. PDF는 지원하지 않습니다. 일정 항목은 시작 시각 지정을 켜서 시각을 입력·수정합니다. 인식된 시각도 보존하며 시각이 없으면 임의의 기본 시각을 표시하지 않습니다. 완료·이월 기호가 기존 기록을 자동 변경하지 않습니다.

원본과 검토 항목은 앱 컨테이너의 Library/Application Support/Sisyphus Almanac/Paper Capture/ReviewDraft.json에 임시 저장됩니다. 저장 성공 또는 초안 삭제 후 이미지와 항목은 비워집니다. 검토창이 열린 동안 저장 실행 취소로 원본 이미지와 수정 초안을 복원할 수 있습니다. 새 이미지 가져오기 또는 초안 삭제 후에는 이전 취소 기회가 사라집니다. 손상 초안·디스크 오류·동시 창의 복구는 보장되지 않으므로 가져온 원본을 별도 보관하고 오류가 나면 창을 닫기 전에 원문과 수정 내용을 확보하세요.

<h2 id="manual-section-9">Mail</h2>

Apple Mail에서 계정을 먼저 설정합니다. Almanac Mail에서 계정 연결과 macOS 자동화 접근을 허용합니다. 계정별 받은편지함 최대 12건을 조회하며 검색은 가져온 목록 범위입니다. 전체 계정의 정확한 미읽음 합계가 아닙니다.

오늘에는 최근 3건이 표시됩니다. 제목 또는 받은편지함 행 선택으로 원본을 엽니다. 방향키 선택 변경도 원본을 열 수 있습니다. ‘메일 앱 열기’는 Apple Mail 자체를 엽니다. 발송·답장·삭제·이동·읽음 변경 기능은 없습니다. 사용자가 원본을 열면 Apple Mail이 읽음으로 처리할 수 있습니다.

자동 갱신 간격 설정은 없으며 처음 로드와 새로고침 버튼을 사용합니다. 모든 메일함·서버 검색·본문·첨부 렌더링은 지원하지 않습니다. 원본 이동·삭제·계정 변경으로 참조가 끊길 수 있습니다.

일정·미리 알림의 자료 연결에서 제목과 message:// 주소 또는 Message-ID로 원본 참조를 붙일 수 있습니다. Daily Log와 Finance의 메일 연결 편집은 아직 제공하지 않습니다.

<h2 id="manual-section-10">메모·Obsidian·Finance</h2>

메모는 Apple Notes 접근을 사용합니다. Obsidian은 사용자가 고른 Vault의 Markdown을 읽으며 북마크로 연결을 복원합니다.

Finance에서 가계부 선택으로 Excel 파일을 연결합니다. OneDrive 파일은 로컬 OneDrive 폴더에서 선택하세요. 연결 확인·원본 열기·다시 선택을 사용합니다. Almanac이 Excel 원본을 수정하거나 금액을 자동 추출하지 않습니다. 로컬 파일 연결은 OneDrive 서버 동기화 완료의 증거가 아닙니다. Daily Log의 OneDrive 자동 백업·복구 기능도 없습니다.

<h2 id="manual-section-11">메뉴바와 문제 해결</h2>

설정에서 메뉴바 아이콘 표시를 전환합니다. 개발 시험 앱과 설치본을 동시에 열면 Dock에 여러 앱이 보일 수 있으므로 Applications의 설치본을 사용하세요.

권한 거부 시 해당 화면의 요청과 시스템 설정을 확인합니다. 새 버전이나 별도 개발 앱은 다른 권한 항목으로 보일 수 있습니다. 실제 개인 자료를 오류 보고에 무심코 첨부하지 말고 앱 버전·재현 순서·오류 문구를 전달하세요. 외부 서비스 전체 회귀가 끝난 정식 안정판은 아닙니다.

<h2 id="development-1-1-4">개발 기록 · 원본을 보며 다시 확인하기</h2>

이번에는 가져온 기록을 검토하고 저장한 기록을 날짜별로 다시 찾아보는 흐름을 다듬었습니다. Paper Capture에서 검토한 원문 기호와 명시한 시각을 보존하고, 열린 검토 창에서 저장을 취소하면 이미지와 항목을 되돌립니다. 날짜별 목록과 완료 목록으로 기록을 다시 살펴볼 수 있습니다. 인식 결과는 계속 원본과 대조해야 하며 복구와 외부 서비스 전체 회귀는 검증이 남아 있습니다.

<h2 id="development-1-1-3">개발 기록 · 적은 것을 다시 살펴보는 과정</h2>

아래는 1.1.0 비공개 시험 시기에 쓴 개발기입니다. 현재 공개 테스트 빌드는 1.1.4입니다.

**Jovaris Audio | macOS 앱 개발기 | v1.1.0**

오픈채팅방에서 누군가 일정과 할 일을 한곳에 모아 관리하는 프로그램을 직접 만들어 쓰고 있다는 이야기를 했다.

그분은 Windows에서 사용하고 있다고 했다.

어떤 프로그램인지 직접 본 건 아니고, 어떻게 만들었는지도 모른다. 그냥 여러 가지를 한곳에 모아 관리한다는 이야기를 듣고 나도 하나 만들어 보고 싶어졌다.

다만 나는 Mac을 사용하니까 내 환경에 맞게 만들기로 했다.

Apple 캘린더와 미리 알림, 메모, 그리고 평소 사용하는 Obsidian까지. 내가 필요한 기능은 넣고 굳이 필요하지 않은 기능은 빼는 식이다.

그래서 만든 게 **Sisyphus Almanac**이다.

### 일정에서 시작하는 앱

처음 생각한 구조는 단순했다.

왼쪽에는 오늘, 예정, 캘린더, 미리 알림, 메모, Obsidian이 있고 가운데에는 캘린더를 둔다. 일정을 선택하면 오른쪽에서 관련 자료를 볼 수 있게 하는 것이다.

예를 들어 피아노 연습 일정이 있다면 그날 연습할 곡이나 지난 연습 메모를 함께 찾아보는 식이다.

음악 작업이든 개인 일정이든 같은 방식으로 사용할 수 있다.

프로젝트 관리 기능이나 칸반 보드도 생각해 볼 수 있겠지만 일단은 뺐다. 편하려고 만드는 프로그램인데 오히려 관리할 게 하나 더 늘어나면 곤란하니까.

처음에는 화면에 샘플 일정부터 표시했다. 그다음 실제 Apple 캘린더와 미리 알림을 연결했고, 일정을 선택하면 관련 자료를 함께 표시하도록 확장했다.

Apple Notes는 목록과 메모 내용을 미리 볼 수 있게 했고, Obsidian은 선택한 Markdown 폴더를 읽는 방식으로 접근했다.

그 과정에서 단순히 자료를 한 번 읽는 것과 앱을 껐다 켠 뒤에도 같은 자료에 접근할 수 있는 것이 전혀 다른 문제라는 것도 확인했다.

### 보기 좋은 앱도 만들고 싶었다

기능을 하나씩 붙이다 보니 화면은 점점 채워졌지만, 그렇다고 보기 좋아진 건 아니었다.

처음에는 Today 화면에 오늘 일정, 할 일, 다가오는 일정 정도만 카드로 배치했다.

그런데 창을 크게 열면 생각보다 너무 허전했다. 산을 배경으로 넣고 색상과 카드도 조정했지만, 결국 중요한 건 화면을 무엇으로 채우느냐였다.

그러다 불렛저널을 생각했다.

이미 일정과 할 일, 메모가 있으니 이걸 단순히 보여주는 데서 끝내지 말고 하루의 기록으로 묶어 보면 어떨까 싶었다.

그래서 Today에 **Daily Log와 Daily Review**를 추가했다.

Daily Log는 생각나는 것을 빠르게 적는 공간이다. 할 일, 일정 초안, 메모, 아이디어를 여러 줄로 작성하고 저장하기 전에 분류 결과를 확인할 수 있다.

불렛저널의 기호도 일반 키보드로 쉽게 입력할 수 있게 바꿨다.

- `*` 할 일
- `X` 완료
- `>` 이월
- `<` 미래로 예약
- `@` 일정
- `-` 메모
- `!` 중요
- `+` 아이디어

예를 들어 `* 믹싱 수정하기`라고 적으면 할 일이고, `+ 새로운 플러그인 아이디어`라고 적으면 아이디어가 된다.

종이 불렛저널을 그대로 따라 하기보다는 Mac에서 쓰기 편한 방식으로 조금 바꾼 셈이다.

Daily Review에서는 끝낸 일과 남은 일을 확인하고 짧은 회고도 남길 수 있다.

남은 일을 무조건 다음 날로 넘기는 방식은 원하지 않았다. 내일 할 일인지, 다음 주에 할 일인지, 아니면 더 이상 필요 없는 일인지 직접 판단하는 게 더 낫다고 생각했다.

그래서 날짜를 직접 선택해 이월하거나 예약하고, 이전 날짜에는 이동 이력을 남기는 방식으로 만들었다. 이월 실행 취소도 시험했다.

하루를 기록한다는 게 거창한 일일 필요는 없다. 그냥 오늘 뭘 했는지, 뭘 못 했는지, 무슨 생각을 했는지 정도만 남길 수 있어도 괜찮다.

### 메뉴바 하나에서 Tuck의 네 번째 구역까지

Almanac에 메뉴바 아이콘을 넣을 때도 고민이 있었다.

MacBook은 노치 때문에 메뉴바 공간이 넉넉하지 않다. 이미 아이콘도 많은데 하나 더 늘어나면 다른 아이콘이 가려질 수도 있다.

그래도 오늘 일정과 할 일을 확인할 때마다 앱 창을 열기보다는 메뉴바에서 간단하게 볼 수 있는 편이 좋겠다고 생각했다.

그래서 Almanac의 메뉴바 아이콘은 기본적으로 표시하되 설정에서 끌 수 있도록 했다.

아이콘은 바위를 밀어 올리는 시지프스 실루엣을 선택했다. 사람과 둥근 바위, 짧은 경사면만 남겨 작은 단색 심벌로 만들었다.

문제는 아이콘 하나를 더 만드는 일이 아니었다. 계속 늘어나는 메뉴바 아이콘을 어떻게 관리할 것인가 하는 문제도 있었다.

마침 별도로 만들고 있던 **Tuck**이 있었다.

Tuck은 메뉴바의 아이콘을 필요에 따라 접고 펼치는 macOS 앱이다.

처음에는 숨길 아이콘과 계속 표시할 아이콘을 나누는 데서 시작했다.

그런데 카카오톡이나 Avid Link처럼 평소에는 접어 두고 싶지만 가끔 바로 꺼내 써야 하는 앱도 있었다.

그래서 가운데 구역을 추가했고, 세 구역을 두 단계로 접는 구조로 발전했다.

그런데 여기서도 문제가 남았다.

아무리 잘 접어도 결국 아이콘을 펼치는 공간은 화면 위쪽이다. 특히 노치가 있는 MacBook에서는 그 공간 자체가 제한적이다.

그래서 **네 번째 구역, Zone 4**를 만들었다.

기존 세 구역은 메뉴바 안에서 아이콘을 정리하고, 네 번째 구역은 메뉴바 아래쪽에 별도로 펼쳐지는 방식이다.

아이콘을 보려고 메뉴바를 계속 가로로 늘릴 필요가 없어진 것이다.

물론 공간을 확보한다고 끝나는 건 아니었다.

아래쪽 구역을 여는 과정에서 로딩 지연도 처리해야 했다. 편하려고 만든 기능인데 열 때마다 답답하면 그건 또 다른 불편이니까.

이 문제까지 수정했고, Zone 4가 포함된 Tuck은 현재 배포 중이다.

Almanac과 Tuck은 별도의 앱이다. 하나는 일정과 기록을 관리하고, 다른 하나는 메뉴바를 관리한다.

그런데 하나를 만들면서 겪은 문제가 다른 하나를 개선하는 데에도 영향을 줬다.

결국 둘 다 내가 Mac을 조금 더 편하게 쓰려고 만든 것들이다.

### 메일도 넣어야 하지 않을까?

처음에는 캘린더와 미리 알림, 메모 정도만 생각했는데 만들다 보니 메일도 필요하겠다는 생각이 들었다.

일정이나 할 일에 관련된 메일이 있는 경우가 많기 때문이다.

예를 들어 믹싱 수정 요청이 메일로 왔다면 그 메일을 작업 일정에 연결해 두는 식이다.

처음에는 메일 제목과 원본 주소를 수동으로 입력해 연결하는 기능부터 만들었다.

실제 Apple Mail에 있는 네이버 메일을 Message-ID로 열어 보는 시험도 진행했다. 별도 샌드박스 시험 앱에서 정확한 원본 메시지가 열리는 것까지 확인했다.

이후 Mail 기능도 확장했다.

최신 1.1.0 개발 자료에서는 Apple Mail에 설정된 활성 계정의 받은편지함에서 계정당 최대 12건의 메일을 조회하고, 제목과 발신자, 날짜, 읽음 상태를 표시하도록 했다.

Today 화면에도 최신 메일 세 건을 배치했다.

이렇게 하면 일정을 확인하다가 메일을 따로 찾아보는 일을 조금 줄일 수 있을 것이다.

다만 Almanac을 새로운 메일 클라이언트로 만들 생각은 없다. 메일을 보내고 답장하고 삭제하는 기능까지 모두 만들려는 건 아니다.

원본은 Apple Mail에 두고 Almanac에서는 필요한 정보를 보고 연결하는 방식이다.

자동 조회 기능은 최신 개발 자료에 포함돼 있지만, 실제 계정별 권한과 전체 동작에 대한 검증은 계속 구분해서 관리하고 있다.

### 가계부까지 연결하다

가계부도 추가했다.

기존에 Excel로 관리하던 가계부가 있다.

이걸 굳이 Almanac 안에 다시 만들 필요는 없겠다고 생각했다. 이미 사용하던 통합 문서가 있고, 그 안에 내가 정리해 둔 정보도 있으니까.

그래서 **Finance** 화면에서 Excel 가계부를 연결하는 방식으로 시작했다.

OneDrive에 있는 파일은 Mac의 OneDrive 폴더에서 선택할 수 있도록 했다.

현재는 Excel 파일을 참조하는 구조다. 앱이 마음대로 셀이나 수식, 서식을 수정하지 않는다.

로컬 OneDrive 폴더에 있는 가계부를 연결하고 파일 내용이 복사본과 같은 것까지 확인했다. 다만 OneDrive 서버에 동기화가 완료됐는지, 연결 버튼으로 Excel 원본이 실제로 열리는지까지는 별도 검증이 필요하다.

월별 지출이나 결제 수단별 비율, 차트 같은 것도 나중에는 넣어 보고 싶다.

하지만 일단은 이미 있는 자료를 제대로 연결하는 게 먼저다.

### 종이에 쓴 기록도 가져오면 어떨까?

불렛저널을 넣으면서 또 하나 생각한 게 있다.

손으로 종이에 기록한 다음 사진을 찍어 Almanac에 가져오면 어떨까?

사진에 있는 글씨를 읽고, 불렛 기호와 날짜를 구분해서, 내가 확인한 뒤 Daily Log에 반영하는 방식이다.

이 기능은 **Paper Capture**라는 이름으로 구상했다.

한글 손글씨를 얼마나 정확하게 읽을 수 있을지, 날짜나 기호를 잘못 인식하면 어떻게 처리할지 등은 아직 확인해야 한다.

그래서 사진을 가져왔다고 바로 일정이나 할 일을 생성하는 방식보다는, 인식 결과를 직접 확인하고 수정한 뒤 저장하는 쪽으로 생각하고 있다.

OneDrive에는 원본 사진이나 Daily Log 백업 사본을 보관하는 방안도 검토하고 있다.

이 부분은 아직 구현 계획이다.

### 왜 시지프스 알마넥인가?

Almanac은 연감이라는 뜻이다. 날짜뿐 아니라 여러 정보와 기록을 함께 담아 놓은 책이다.

시지프스는 매일 바위를 밀어 올리는 사람이고.

오늘 할 일을 끝내면 내일 할 일이 생기고, 작업 하나가 끝나면 또 다른 작업이 기다린다.

어쩌면 일상도 바위를 계속 밀어 올리는 일과 비슷한 것 같다.

그래도 매일 똑같은 건 아니다. 그 안에서 무언가를 만들고, 배우고, 기록을 남긴다.

그런 것들을 하나의 연감처럼 모아 보고 싶었다.

그래서 디자인 문구도 이렇게 정했다.

### 지금은 v1.1.0

Sisyphus Almanac은 Swift와 SwiftUI로 만든 macOS 전용 앱이다.

현재 개발 버전에는 Calendar, Reminders, Notes, Obsidian, Mail, Daily Log, Daily Review, 메뉴바 요약, Finance 파일 연결 등이 포함돼 있다.

처음에는 일정과 할 일을 한곳에 모아 보고 싶다는 생각이었는데, 지금은 그날의 기록과 관련 자료까지 이어지는 프로그램이 됐다.

빌드와 일부 기능 시험은 통과했지만, 실제 사용 환경에서 모든 기능이 함께 안정적으로 동작하는지는 계속 확인해야 한다.

그래서 **v1.1.0은 개인용 개발 버전**으로 관리하고, GitHub의 비공개 저장소에 보존하는 방향으로 정했다.

공개 웹사이트에는 개발 과정과 샘플 화면을 소개하되, 앱 자체를 공개 다운로드로 배포하는 단계는 아니다.

반면 별도로 개발한 Tuck은 네 번째 구역과 로딩 지연 개선을 반영해 이미 배포 중이다.

처음에는 오픈채팅방에서 Windows용 프로그램을 직접 만들어 쓴다는 이야기를 들은 게 시작이었다.

나는 거기서 아이디어를 얻어 내 Mac에 맞는 프로그램을 만드는 중이다.

거창한 생산성 도구를 만들겠다는 생각보다는, 그냥 내가 편하게 쓸 수 있는 프로그램 하나 있었으면 좋겠다는 마음이다.

어차피 매일 바위를 굴려야 한다면, 오늘 굴릴 바위가 뭔지는 한눈에 보고 싶으니까.
