## 이번 공개판

차이제곱은 음악 연습과 실제 제작 작업을 같은 흐름에서 기록하는 개인 작업실입니다. 이번 공개판은 공개 샘플을 누구나 로그인 없이 볼 수 있게 하고, 로그인한 사용자는 자신의 주간 목표, 오늘 할 일, 연습 기록, Logic 프로젝트, Pro Tools 믹싱 세션과 주간 리뷰를 한곳에서 관리할 수 있게 정리했습니다.

## 주요 변경 사항

### 공개 샘플과 개인 기록 분리

- 제작자가 실제로 남긴 2026년 11월 연습 기록 4회를 공개 샘플로 제공합니다.
- 공개 기록에는 모두 `샘플` 또는 `Sample` 배지를 표시합니다.
- 로그인하지 않은 방문자는 샘플 대시보드, 날짜별 기록과 주간 리뷰를 볼 수 있습니다.
- 로그인한 사용자의 개인 기록은 공개 샘플과 분리되며, 계정별 개인 작업실에서만 불러오고 수정합니다.

### 한국어와 영어 지원

- 한국어 기본 화면과 `/en` 영어 화면을 제공합니다.
- 대시보드, 입력 창, 템플릿, 주간 리뷰와 공개 샘플을 두 언어로 볼 수 있습니다.
- 언어를 바꿔도 같은 계정의 개인 기록을 사용합니다.
- 사용자가 직접 입력한 제목과 메모는 자동 번역하지 않고 입력한 언어 그대로 보존합니다.

### 대시보드 개편

- 보라색 `내 연습` 헤더와 주간 대시보드를 복원했습니다.
- 이번 주 연습 시간, 평균 성공률, 목표 달성 수와 진행 중인 프로젝트를 한 화면에 표시합니다.
- 주간 목표, 오늘 할 일, 오늘 연습 기록, 발전도, 프로젝트 현황, 반복해서 막힌 항목과 최근 기록을 이어서 확인할 수 있습니다.

### 실제 연습 흐름에 맞춘 분야 구성

- 피아노, 리듬, 편곡, 카피, 기타, 시창, 화성학, 보컬과 베이스를 같은 수준의 분야로 기록합니다.
- 피아노는 전공 수준의 재즈 과제 중심이 아니라 멜로디 4마디, 박 나누기, 카피, 양손 연결처럼 현재 연습에 바로 쓸 수 있는 흐름을 기본으로 합니다.
- 연습 분야와 작업 위치를 분리해, 같은 카피라도 Logic Practice인지 Logic Projects인지 구분할 수 있습니다.

1도 `도도`부터 8도 `도–높은 도`까지 음정을 하나씩 연습한 뒤, 반복음과 여러 음정을 잇는 종합 패턴을 부릅니다. 2도는 `도레 · 레미`, 3도는 `도미 · 레파 · 미솔`로 시작음을 옮겨 부릅니다. 개별 음정 8개와 종합 1개를 포함해 템플릿은 총 9개입니다. 난이도는 건반 먼저 치고 따라 부르기, 건반 치면서 같이 부르기, 먼저 부르고 건반으로 확인하기 순입니다. 패턴과 난이도별 기록 횟수와 평균 성공률을 확인할 수 있습니다.

### Logic과 Pro Tools 작업 구분

- `Logic Practice`: 연습, 카피, 리듬과 짧은 녹음
- `Logic Projects`: 편곡과 제작 프로젝트
- `Pro Tools 믹싱`: 상위 프로젝트 아래 곡별 독립 믹싱 세션

Pro Tools 세션은 `YYMMDD_차수_곡명_Mix` 형식을 기준 예시로 제공합니다.

### 기록 항목과 분석

- 날짜, 연습 시간, 템포, 성공률, 메모, 녹음·결과물, 완료 기준과 막힌 항목을 한 입력 창에서 기록합니다.
- 같은 연습 항목의 성공률 또는 BPM 변화를 1주와 4주 단위로 확인할 수 있습니다.
- 같은 막힌 항목을 여러 날 같은 이름으로 기록하면 반복 항목으로 묶습니다.
- 주간 리뷰에서 지난주와 이번 주의 시간, 기록 수, 평균 성공률, 목표 달성과 분야별 연습 시간을 비교합니다.
