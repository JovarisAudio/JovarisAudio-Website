### 1.0.0 — MenuHider

⌘-드래그로 숨길 구역을 정하고, 화살표 버튼으로 한 구역을 접거나 펼칠 수 있었습니다. 설정 창에서 로그인 시 자동 실행과 마지막 표시 상태 복원을 설정할 수 있었으며, Apple Silicon·Intel Universal DMG를 만들었습니다. 공개 릴리즈 여부는 확인되지 않았습니다.

### 1.0.1 — MenuFold

MenuHider를 MenuFold로 이름을 바꾸고 기존 한 구역 접기·펼치기 동작을 유지했습니다. 새 이름으로 Universal 설치 파일을 준비했습니다. 공개 릴리즈 여부는 확인되지 않았습니다.

### 1.0.2 — Tuck

이름과 아이콘을 Tuck으로 바꾸고 밝은 오크색 접기 버튼, 짙은 나무색 옵션 버튼, 나무결 설정 팝오버와 나무 테마 DMG를 적용했습니다. 메뉴 막대 전용으로 전환하고 팝오버 자동 닫힘, 로그인 자동 실행 및 승인 상태 표시, 선택적인 마지막 상태 복원을 적용했습니다. macOS Sequoia 15.8의 Apple Silicon Mac에서 기본 접기·펼치기를 확인했습니다. 전체 호환성 및 공개 릴리즈 여부는 확인되지 않았습니다.

### 1.0.3 — 버전 통일과 GitHub 업로드

앱과 Universal DMG·ZIP을 1.0.3으로 맞추고 1.0.2 DMG 변형을 이전 버전으로 보관했습니다. 소스와 패키지를 GitHub `main`에 올렸으며 로컬 앱 교체와 실행을 확인했습니다. 실제 로그아웃·재로그인 후 자동 실행은 다시 시험하지 않았고, GitHub Releases 게시 여부는 확인되지 않았습니다.

### 1.0.4 — 세 구역 로컬 테스트

왼쪽에 가끔 쓰는 앱, 가운데에 빠르게 꺼낼 앱, 오른쪽에 항상 표시할 앱을 배치하는 세 구역과 두 접기 경계를 도입했습니다. 밝은 나무 버튼으로 완전히 접기, 가운데 구역 펼치기, 모두 펼치기를 순환했습니다. 개발 Mac에 설치한 로컬 테스트판으로, GitHub 업로드와 공개 릴리즈 여부는 확인되지 않았습니다.

### 1.0.5 — 버튼 통합

밝은 나무 버튼을 없애고 짙은 나무 버튼 하나에 접기와 옵션을 통합했습니다. 왼쪽 클릭은 세 상태 순환, 오른쪽 클릭은 옵션 열기로 설정했고 마지막 상태 복원을 세 상태에 적용했습니다. 로컬 실행과 Universal DMG·ZIP 및 체크섬의 GitHub `main` 업로드를 확인했습니다. GitHub Releases 게시 여부는 확인되지 않았습니다.

### 1.0.6 — 딱따구리 경계

맨 왼쪽 경계선을 오른쪽을 보는 딱따구리 그림으로 바꾸어 로컬에서 시각적으로 평가했습니다. 로컬 디자인 테스트였으며 공개 릴리즈 여부는 확인되지 않았습니다.

### 1.0.7 — 두 다람쥐

왼쪽에는 오른쪽 위로 달리는 다람쥐, 가운데 구역의 오른쪽 경계에는 도토리를 안고 달리는 다람쥐를 적용했습니다. 로컬 디자인 테스트였으며 공개 릴리즈 여부는 확인되지 않았습니다.

### 1.0.8 — 다람쥐와 굴러가는 도토리

작은 메뉴 막대에서 읽기 쉽도록 달리는 자세와 바람선, 발밑 땀방울을 다듬고 오른쪽 그림을 굴러가는 도토리 하나로 바꿨습니다. 각 그림 옆에 오른쪽을 가리키는 `>`를 넣었습니다. DMG 제목과 설치 안내, 개발자 표기 및 네 항목의 배치를 가운데로 맞췄습니다. 로컬 실행을 확인하고 Universal DMG 안의 앱을 검사했습니다. GitHub 업로드 및 공개 릴리즈 여부는 확인되지 않았습니다.

### 1.1 — GitHub 릴리즈

세 구역, 두 단계 접기와 버튼 하나로 조작하는 방식을 한데 담았습니다. 다람쥐와 도토리가 두 접기 경계를 표시합니다. DMG 안내를 가운데 정렬하고 Finder 항목 이름 네 개를 각 라벨 상자 중앙에 배치했습니다.

- 2026년 11월 15일 GitHub Releases에 1.1 게시
- DMG·ZIP 체크섬을 업로드된 파일과 대조했고 Apple Silicon Mac에서 설치와 실행을 확인했습니다.
- macOS 13 이상, Apple Silicon·Intel Universal입니다. Intel 실기기 실행과 실제 재로그인 후 자동 실행은 검증 대기입니다.
- ad-hoc 서명 빌드이며 Apple 공증을 받지 않았습니다.

### 2.1 — 실험 기능 Zone 4

나무 배경의 Zone 4와 Edit 항목 선택, 아이콘에 마우스를 올렸을 때 이름 표시를 추가했습니다. Edit은 앱을 백그라운드에서 한 번에 최대 네 개씩 조회했습니다. 당시 속도 개선은 실측하지 않았습니다.
